Database & Security

Bekal penting pengelola data dan pertahanan dari serangan siber. Klik tiap topik untuk membuka penjelasannya.

4 topik Level: Menengah

SQL memakai tabel dan relasi dengan skema tetap, sedangkan NoSQL menyimpan data dalam beragam model dengan skema dinamis.

  • SQL — MySQL, PostgreSQL, Oracle; kuat untuk transaksi dan laporan dengan JOIN.
  • Document — MongoDB; data dalam bentuk JSON yang fleksibel.
  • Key-Value — Redis; sangat cepat untuk cache dan sesi.
  • Column & Graph — Cassandra untuk skala besar, Neo4j untuk relasi kompleks.
  • Kapan memilih — SQL untuk data sangat terstruktur dan transaksi; NoSQL untuk data tak terstruktur dan skala besar.

Mnemonic

SQL untuk keseragaman, NoSQL untuk fleksibilitas.

Normalisasi menghilangkan redundansi (data ganda) dengan memecah tabel menjadi tabel-tabel yang lebih bersih dan saling berelasi.

  • 1NF — tiap sel berisi satu nilai (atomic); buang kolom yang berulang.
  • 2NF — singkirkan ketergantungan parsial ke sebagian kunci.
  • 3NF — singkirkan ketergantungan transitif (kolom tergantung kolom non-kunci).
  • Anomali yang dicegah — insert, update, dan delete yang merusak konsistensi data.

Aturan emas

Kalau kamu mulai copy-paste data yang sama di banyak baris? Itu tanda belum normal.

Cybersecurity melindungi sistem, jaringan, dan data dari serangan digital. Konsep intinya disebut CIA Triad.

  • Confidentiality — data hanya diakses pihak berwenang (enkripsi, ACL).
  • Integrity — data tidak diubah tanpa izin (hash, tanda tangan digital).
  • Availability — sistem tetap berjalan (backup, proteksi DDoS).
  • Ancaman umum — phishing, malware, SQL injection, brute force, social engineering.
  • Praktik baik — password kuat + 2FA, update rutin, prinsip least-privilege.

Waspada

Tautan "bank" yang meminta OTP adalah phishing. Baca alamat situsnya dulu, jangan asal klik.

Enkripsi melindungi kerahasiaan data saat disimpan maupun dikirim, dengan mengubah plaintext menjadi ciphertext.

  • Simetris — satu kunci untuk enkripsi & dekripsi; cepat (AES, DES).
  • Asimetris — sepasang kunci publik & privat; dipakai RSA, PGP, HTTPS.
  • Hashing — satu arah dan tak bisa dibalik; untuk penyimpanan password (bcrypt, SHA-256).
  • Dunia nyata — HTTPS, VPN, dan e-wallet memakai kombinasi teknik ini.

Best practice

Simpan password cukup dengan hash + salt. Jangan pernah menyimpan password dalam bentuk plaintext.
