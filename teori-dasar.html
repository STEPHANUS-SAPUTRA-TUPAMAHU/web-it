Pahami fondasi cara internet dan jaringan bekerja. Klik tiap topik untuk membuka penjelasannya.

4 topik Level: Pemula

OSI (Open Systems Interconnection) adalah model referensi yang membagi proses komunikasi jaringan menjadi 7 lapisan. Setiap lapisan punya tugas spesifik dan berkomunikasi dengan lapisan di atas maupun di bawahnya.

  • Layer 7 Application — antarmuka aplikasi (HTTP, FTP, SMTP).
  • Layer 6 Presentation — enkripsi dan konversi format data.
  • Layer 5 Session — mengelola sesi komunikasi antar-host.
  • Layer 4 Transport — pengiriman andal via TCP/UDP lengkap dengan port.
  • Layer 3 Network — routing dan pengalamatan IP.
  • Layer 2 Data Link — frame dan alamat MAC.
  • Layer 1 Physical — media fisik: kabel, sinyal, bit.

Tips menghafal

"Please Do Not Throw Sausage Pizza Away" — huruf awal tiap layer dari atas ke bawah.

Topologi menentukan cara node (komputer, server, switch) saling terhubung. Pilihannya memengaruhi biaya, kecepatan, dan ketahanan jaringan.

  • Star — semua node ke pusat; paling umum, mudah dirawat, tapi lumpuh jika pusat gagal.
  • Bus — satu kabel utama; murah, tapi rawan tabrakan data.
  • Ring — node terhubung melingkar; data mengalir searah.
  • Mesh — semua node terhubung semua; sangat andal tapi mahal.
  • Tree — gabungan star bercabang; cocok untuk jaringan hierarkis.

Fakta

WiFi di rumah kamu hampir pasti pakai topologi STAR — karena hanya ada satu router pusat.

IP (Internet Protocol) Address adalah identitas logis sebuah perangkat. Ada dua versi: IPv4 (32-bit, contoh 192.168.1.1) dan IPv6 (128-bit, contoh 2001:db8::1) untuk mengatasi kelangkaan alamat.

  • IPv4 — 4 oktet 0 sampai 255; total sekitar 4,3 miliar alamat.
  • IPv6 — 8 kelompok hexadesimal; jumlah alamat hampir tak terbatas.
  • Alamat privat — 10.x, 172.16-31.x, 192.168.x; dipakai LAN dan diterjemahkan NAT ke internet.
  • Subnet mask — membagi jaringan jadi subnet; contoh 255.255.255.0 sama dengan /24.
  • Localhost — 127.0.0.1 adalah alamat perangkat sendiri untuk pengujian.

Fakta

DHCP dan DNS adalah dua protokol yang paling sering bekerja sama dengan IP agar kamu bisa "tinggal pakai" internet tanpa konfigurasi manual.

Protokol adalah kumpulan aturan untuk pertukaran data. Tanpa protokol, dua perangkat dari vendor berbeda tidak akan bisa berkomunikasi sama sekali.

  • TCP/IP — fondasi internet; TCP memastikan data utuh, IP menangani pengalamatan.
  • UDP — pengiriman cepat tanpa kepastian sampai; cocok untuk streaming dan game.
  • HTTP/HTTPS — protokol web; HTTPS adalah versi terenkripsi lewat TLS.
  • DNS — menerjemahkan nama domain (mis. google.com) ke alamat IP.
  • DHCP — memberi alamat IP otomatis ke perangkat yang baru bergabung.

Fakta

HTTPS adalah alasan munculnya ikon gembok di address bar browser kamu.
